# NMS Saves Manager

**Quick Start Guide**

Download zip, extract and rename directory to app then run app.exe  
enter <user_id> and <steam_id>  
Steam > Settings > Account > Account Details > Steam ID: (17 digits)

Navigate to http://localhost:5000
